# pomo•focus

Timer Pomodoro minimalista com design dark, troca de fases automática e persistência de sessões.

## Demonstração

Link do projeto: https://eduardoadf-dev.github.io/Pomodoro/

## Funcionalidades

- Timer com fases automáticas: **Foco → Pausa curta → Pausa longa**
- 4 ciclos por rodada, com pausa longa ao final
- Anel de progresso animado
- Cores e ambient glow que mudam por fase
- Beep sonoro ao fim de cada fase
- Contador de pomodoros persistido no `localStorage`
- Título da aba atualizado em tempo real
- Responsivo para mobile

## Tecnologias

- HTML
- CSS
- JavaScript (vanilla)
- Web Audio API

## Como usar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Não requer instalação ou dependências
